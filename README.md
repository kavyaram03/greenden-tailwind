# Greenden 🌿

Greenden is a responsive multi-page website designed using **HTML and Tailwind CSS**. The project focuses on creating a clean, modern, and user-friendly interface while practicing Tailwind CSS utility classes and responsive design techniques.

## 📌 Features

* Responsive navigation bar
* Attractive home page with hero section
* Products page with responsive product cards
* Contact page with contact information and form
* Responsive layouts for mobile, tablet, and desktop screens
* Built using Tailwind CSS utility classes
* Uses Flexbox and CSS Grid for layout and alignment
* Clean and modern user interface

## 📄 Website Pages

### 🏠 Home

Introduces Greenden with a hero section, featured products, customer reviews, newsletter section, and footer.

### 🛍️ Products

Displays a collection of plant-related products using a responsive grid-based card layout.

### 📞 Contact

Provides contact information along with a structured form for user interaction.

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS

## 🎯 Learning Objectives

This project was created to practice:

* Building multi-page websites using HTML
* Using Tailwind CSS utility classes
* Creating responsive layouts
* Working with Flexbox and CSS Grid
* Managing spacing, alignment, typography, and responsive breakpoints
* Designing clean and user-friendly interfaces

## 📱 Responsive Design

Greenden is designed to adapt to different screen sizes, including mobile phones, tablets, and desktop devices using Tailwind CSS responsive utilities such as `sm:`, `md:`, and `lg:`.
